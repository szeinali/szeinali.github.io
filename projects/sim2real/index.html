Sim-to-real manipulation: project log

Training a robot-arm policy in GPU-parallel simulation, making it robust with domain randomization, and transferring it to a real low-cost arm. Every result is measured with the same evaluation protocol and published here as it happens.

Roadmap

  • doneDay 0: evaluation protocol, metrics schema, numpy baseline
  • nextWeek 1: MuJoCo reach task + PPO/SAC baseline; compare against Day 0 on the same metrics
  • plannedWeek 2: GPU-parallel training (MJX / Isaac Lab); throughput scaling vs. number of envs
  • plannedWeek 3: domain randomization (friction, mass, latency, camera) + ablation of what matters
  • plannedWeek 4: transfer to a real SO-101 arm; sim vs. real success over repeated trials, failure analysis
Code: code/sim2real. Charts render from the JSON in data/, and every number is reproducible from the scripts.
